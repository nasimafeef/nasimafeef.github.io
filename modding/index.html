Modding

Add new cars to drive and new cars for the traffic, with vehicle packs.

A vehicle pack is a small add-on folder you copy onto your phone. The game loads it when it starts; nothing in the installed game changes, and you can remove it any time.

  • Drivable cars appear in the garage after the built-in ones.
  • Traffic cars are mixed into the traffic on the roads.
  • Packs are made on a Windows PC with the free Unreal Engine 5.8 and our Mod Kit.

Install a vehicle pack

  1. Get the pack's folder (for example RaviCars) from its author. It contains a .uplugin file and a Content folder.
  2. Connect your phone to a computer, or use a file manager app, and copy the whole folder to: 
    Android/data/com.evastudios.vehiclesimulator/files/UnrealGame/VehicleSimulator/VehicleSimulator/Plugins/GameFeatures/
    Create the Plugins/GameFeatures folders if they don't exist yet.
  3. Restart the game.
  4. On the main menu tap Mods. The pack should say Loaded and list its cars. If it says Could not load, the reason is shown underneath.

To remove a pack, delete its folder and restart the game.

Packs are made for one version of the game. After a game update, a pack only loads once its author rebuilds it for the new version. In multiplayer, everyone needs the same packs: the host refuses cars it doesn't have.

Make your own

This is the outline. The Mod Kit contains the full step-by-step guide, with every setting explained.

What you need

  • A Windows PC and Unreal Engine 5.8 (free, from the Epic Games Launcher, with the Android target platform ticked).
  • The Mod Kit for the current version of the game.
  • A 3D car model you have the rights to. The kit contains no car models; Unreal's own sports car template is fine for learning.
  • For testing: an Android phone with USB debugging.

The steps

  1. Create your pack. One script creates it: pick a short one-word name. It becomes the start of every vehicle id in the pack, like ravicars.swift.
  2. Add a drivable car. Import a skeletal mesh with one bone per wheel, make a small wheel animation Blueprint, and a vehicle Blueprint based on the kit's BP_VehiclePawnBase. Driving, fuel, cameras, sounds and multiplayer all come from it. Then a vehicle definition puts the car in the garage.
  3. Add a traffic car. Only a model is needed, and a static mesh is fine. A traffic definition sets how common it is and how fast it drives.
  4. Check it. Right-click your pack → Validate Assets. The kit flags anything that won't work on phones or won't build.
  5. Build and install. One script builds the installable folder, and can copy it straight to a connected phone.

Tips

  • Keep cars light: drivable cars under 30,000 vertices, traffic cars under 10,000, with LODs, textures at most 2048 px, and Nanite off. Phones don't support Nanite.
  • Engine torque curve: keep its keys linear. A curved key with a steep tangent can dip below zero between keys, and the car then drives backwards when pulling away.
  • Traffic car driving backwards? Set its Mesh Yaw Offset to 180.
  • Car floating, sinking or flipping? The wheel bone names don't match the skeleton, the wheel radius is wrong, or the model's pivot isn't at ground level.

Rules

  1. Only content you have the rights to. No models or textures taken from other games.
  2. Everything in the pack. A pack may use its own files and what the game ships; nothing else.
  3. No scripts. Blueprints may add components and change values, but not add logic. Phones can't load code from a pack.
  4. Ids start with your pack name, lowercase: <pack>.<vehicle>. Never change an id once people use the pack; saves refer to it.
